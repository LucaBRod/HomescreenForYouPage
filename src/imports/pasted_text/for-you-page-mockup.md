Create a **mobile “For You” page** for a teen mental health / social media reflection app.

This is a **mockup to show teens and get feedback**, not a final product. Keep it visually strong but relatively simple so we do not overbuild the prototype.

## Overall design

Use the **current For You page I provide as the main design reference**. Match its:

* color palette
* typography
* card shapes
* spacing
* icons
* overall visual style

Do **not** use the space theme from the Apollo hackathon mockup.

However, use the Apollo mockup and the mental-health app examples I provide as inspiration for how the data are displayed:

* playful graph titles
* emojis and icons integrated into graphs
* different types of visualizations
* graphs that feel personal rather than clinical
* soft animations/interactions
* plain-language takeaways above or alongside the data

The page should feel **warm, modern, teen-friendly, personalized, and easy to scan**.

Use one vertically scrollable page with the following structure.

---

# 1. Streak / Check-In Section

At the very top, show the user's current check-in streak.

Example:

**🔥 5 Days in a Row**

Below it, show the last seven days using small circles, icons, or checkmarks:

**M ✓  T ✓  W ✓  T ✓  F ✓  S ○  S ○**

This should feel rewarding but not competitive.

Use a subtle animation concept where completed days fill in or gently pop into place.

---

# 2. Personalized Patterns

Below the streak, create one main section for the user's personalized data.

Use the heading:

**Your Patterns**

or another short, friendly heading that fits the existing app design.

Include **only five graph cards**.

Do not add additional graphs.

## Graph 1: Mood Over Time

This should be one of the most visually prominent cards.

Mirror the style of the mood-tracking example I provide.

Show mood across several days as a smooth line chart.

### Important visual details:

* Each mood level should have a **different emoji**
* Each mood level should also have a **different color**
* The emoji appears directly on or near each data point
* The line rises and falls with the user's mood
* The graph should feel expressive and intuitive rather than statistical

For example:

😞 very bad
😕 bad
😐 neutral
🙂 good
😊 very good

Use the corresponding mood color at each point.

Include:

**7 Days | 30 Days**

Possible title:

**How You've Been Feeling**

Include a short takeaway such as:

**“Your mood has been a little more positive this week.”**

If animation is shown, have the line gently draw itself from left to right and the emojis appear as each point is reached.

---

## Graph 2: A Pattern We Noticed / Correlation

Mirror the **correlation-style visualization from the mental-health app reference I provide**.

The purpose is to show a relationship between two things the user tracks without making it look overly scientific.

Example:

**A Pattern We Noticed**

**“On days with more social comparison, your mood tends to be lower.”**

Show the relationship visually using a simple correlation-style graph or paired trend visualization.

Keep it colorful, friendly, and easy to understand.

Do not display technical statistics like *r*, p-values, or “correlation coefficient.”

Add small supporting text:

**“This is just a pattern in your check-ins — it doesn't necessarily mean one causes the other.”**

Other example relationships the design could eventually support:

* more comparison ↔ lower mood
* more intense comparisons ↔ lower mood
* scrolling ↔ stronger negative feelings

Only show **one** relationship in this mockup.

---

## Graph 3: When Comparison Shows Up

Show **what time of day social comparison happens most often**.

Possible time periods:

🌅 Morning
☀️ Afternoon
🌆 Evening
🌙 Night

Use a visual that feels more interesting than a standard bar chart.

Possible styles:

* a horizontal day timeline
* different-sized circles along a day
* icons representing each part of the day

Example headline:

**When Comparison Shows Up**

Example insight:

Use the time-of-day icons and colors as part of the visualization.

## Graph 5: Comparison Frequency

Show how often social comparison has occurred over time.

This should answer something like:

**“How often has comparison been showing up?”**

Possible visualization:

* a simple weekly trend
* dots representing comparison days
* a mini calendar-style visualization
* a clean line or bar visualization if that works best with the existing design

Example:

**Comparison This Week**

Mon: 1
Tue: 0
Wed: 2
Thu: 1
Fri: 3
Sat: 0
Sun: 1

But display this visually rather than as a table.

Include a takeaway such as:

**“Comparison showed up less often this week than last week.”**

If there is not enough past data to make that statement, use something simple such as:

**“You noticed comparison on 4 days this week.”**

# 3. Your Activity

After all five personalized-pattern cards, keep the **existing “Your Activity” section from the current For You page**.

Move it to the bottom of the page rather than removing it.

Keep the same basic functionality and visual style where the user can see what they did on each day.

This section should feel like the detailed history underneath the higher-level personalized insights.

The hierarchy should therefore be:

**Streak**

↓

**Your Patterns — 5 graphs**

↓

**Your Activity — daily history**

## Overall graph design principles

Across the five graphs:

* Do not make every graph look the same.
* Use rounded shapes and the existing app's soft visual style.
* Use emojis and icons when they help communicate meaning.
* Use colors meaningfully rather than decoratively.
* Lead with a short plain-language takeaway.
* Then show the visualization.
* Avoid clinical or statistical language.
* Avoid clutter and excessive labels.
* Keep graphs understandable at a glance.
* Use subtle animation concepts where helpful:

  * line drawing into place
  * bars gently growing
  * emojis popping in
  * streak circles filling
  * insight text fading in

Keep animations subtle and soothing, not flashy.

## Important

This is a **concept prototype for teens to react to**, so prioritize testing these specific ideas:

1. Do teens like seeing the streak first?
2. Do they understand and like the emoji/color mood graph?
3. Do they find the correlation-style “A Pattern We Noticed” card useful?
4. Which of the five personalized graphs do they care about most?
5. Do they like seeing personalized patterns before their detailed daily activity history?
